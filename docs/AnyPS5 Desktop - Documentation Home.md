# AnyPS5 Desktop documentation home

AnyPS5 Desktop is the Flutter launcher for PS5 games. This fork adds PS1, PS2 and PS3 games through emulators, and online play for them.

- [Emulator configuration](<AnyPS5 Desktop - Emulator Configuration.md>) covers setup, the library, playing and online play.
- [Retro host process](<AnyPS5 Desktop - Retro Host Process.md>) covers how emulated games run in the separate anyps5-retro-host program and what the launcher keeps.
