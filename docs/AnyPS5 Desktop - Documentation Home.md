# AnyPS5 Desktop documentation home

AnyPS5 Desktop is the Flutter launcher for PS5 games. This review branch
adds optional embedded retro play on Windows x64.

- [Emulator configuration](<AnyPS5 Desktop - Emulator Configuration.md>) covers setup, library formats, the Quick Menu, graphics, testing and release gates.
- [Emulator multiplayer design](<AnyPS5 Desktop - Emulator Multiplayer Design.md>) covers local-copy online play through native game networking, virtual LAN, and synchronized emulation.
- [Combined laptop setup](<AnyPS5 Desktop - Combined Laptop Setup.md>) identifies the combined source snapshot, Linux build route, existing port reference and remaining cross-platform online blockers.
- [Linux embedded emulators](<AnyPS5 Desktop - Linux Embedded Emulators.md>) explains the Linux native host, managed emulator setup, platform capabilities and verification.
