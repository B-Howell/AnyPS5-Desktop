# AnyPS5 Desktop documentation home

AnyPS5 Desktop is the Flutter launcher for PS5 games. This fork adds optional embedded retro play and AnyTogether multiplayer work. The current [Windows and Linux acceptance requirements](<AnyPS5 Desktop - Emulator Multiplayer Design.md#product-direction>) require one all-features launcher and a lobby started from the running game's PS Quick Menu.

- [Emulator configuration](<AnyPS5 Desktop - Emulator Configuration.md>) covers setup, library formats, the Quick Menu, graphics, testing and release gates.
- [Emulator multiplayer design](<AnyPS5 Desktop - Emulator Multiplayer Design.md>) covers local-copy online play through native game networking, virtual LAN, and synchronized emulation.
- [Retro host process](<AnyPS5 Desktop - Retro Host Process.md>) covers how embedded games run in the separate anyps5-retro-host program and what the launcher keeps.
